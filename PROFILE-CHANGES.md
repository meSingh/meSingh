## To publish an update (from 3 Nov 2026: push from this folder)

This folder is the clone of `meSingh/meSingh` (remote `origin`, branch `master`) since 3 Nov 2026. Edit, regenerate, commit, `git push`. No throwaway clone. The pre-3 Nov local history (v4 to v8 as separate commits) is on the local branch `design-history`.

## The old way (until 3 Nov 2026, kept for the record)

```bash
git clone git@github.com:meSingh/meSingh.git /tmp/meSingh-profile
cd /tmp/meSingh-profile
git rm -rq banner.png public .vscode
SRC=~/Sites/PersonalBranding-Code/github-profile
cp -R "$SRC/README.md" "$SRC/assets" "$SRC/data" "$SRC/scripts" "$SRC/.github" .
git add -A
git commit -m "Profile v3: production-AI profile with generated live cards"
git push
```

For an update, edit `README.md` or `data/facts.json` in the code folder, regenerate, then copy the same set over and push. Pushes that touch `data/facts.json` or `scripts/` rerun the workflow automatically.

## PROFILE_TOKEN

Added 7 Sep 2026 as a repository secret. `scripts/fetch.mjs` uses it (all-time commit and PR totals in `data/github.json` now include private repositories). The summary-cards action does **not** use it: its profile-details query reads the account email and the token lacks the `user:email` scope, so the run with that token produced no profile-details or stats card and the live page briefly showed broken images. The action runs on the Actions token, which only counts public activity. To have the summary cards count private work too, regenerate the personal token with the `user:email` scope (or the full `user` scope) and set both summary-cards steps back to `${{ secrets.PROFILE_TOKEN }}`.

## What the numbers on the ledger mean

- Uptime timers are computed at generation time from the dates in `facts.json` (Shiprocket Feb 2016, ValueLabs May 2018, git.wtf Oct 2016). They tick over monthly.
- "Day N" under the role counts from Oct 2025, when the TWINii engagement started, not from the Chief Architect title in Feb 2026.
- Contributions, private share, stars, repos and account age come from the GraphQL API. The private share (90% today) is `restrictedContributionsCount / totalContributions`.
